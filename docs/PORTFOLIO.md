# Portfolio description

## COLA Fuel-Price Sensitivity

Built a Python decision-support pipeline using official BLS CPI-W, fuel-price, and truck-transportation PPI series to estimate how gasoline and diesel-related price shocks could affect the next Social Security COLA. Implemented SSA's third-quarter calculation, raw-versus-rounded threshold diagnostics, seasonal baseline forecasting, direct fuel-weight counterfactuals, a two-stage lagged diesel-to-freight-to-consumer pass-through model, scenario grids, and historical validation while clearly separating exact COLA arithmetic from exploratory assumptions.
