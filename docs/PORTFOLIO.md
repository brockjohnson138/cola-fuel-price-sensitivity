# Portfolio description

## COLA Fuel-Price Sensitivity

Built a reproducible Python decision-support pipeline using official BLS CPI-W, fuel-price, and truck-transportation PPI series to estimate how gasoline and diesel-related price shocks could affect the next Social Security COLA. Implemented SSA's third-quarter calculation, raw-versus-rounded threshold diagnostics, seasonal baseline forecasting, direct fuel-weight counterfactuals, a two-stage lagged diesel-to-freight-to-consumer pass-through model, scenario grids, generated visualizations, and historical validation while clearly separating exact COLA arithmetic from exploratory assumptions.

**Portfolio result:** The current pre-release snapshot estimates a provisional raw COLA of 3.446% (3.4% after one-time rounding). The README reports the next-tenth threshold and the exploratory diesel shock required to cross it, while preserving the September-release limitation.
